# Animation asset provenance

The default `comunicare.procedural.v1` motions are original procedural recipes
created for this project on 2026-11-03, not downloaded motion capture or converted
third-party clips. The eight recipes in `scripts/assets/default_animations.gd`
are dedicated to the public domain under **CC0-1.0**. See
`assets/animations/manifest.json` and `assets/animations/CC0-1.0.txt`.

The animation code constructs quaternion keys directly; no external rig/model or
paid asset is included. These are simple baseline motions, not a claim of
production-quality captured locomotion. Quaternius remains a candidate for a
future audited replacement; no Quaternius or Mixamo data is bundled here.

User-imported files retain their own licensing. Importing or hashing a file does
not grant redistribution rights. Sharing requires the owner's explicit consent
and permission to distribute the motion.
